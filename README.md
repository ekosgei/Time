## Whad does this application do? 

The application allows users to track their projects, hobbies, and activities by recording when they started, how many days have passed, and how many times they have participated. The application aims to help users better visualize their progress over time. 

## Who will use it?
Our target audience is anyone interested in improving their skills or abilities through consistent practice and tracking their progress.

## Why is this project of interest to me 
We are interested in developing this app because we value the idea that consistent practice leads to improvement, and we believe the app can help people better visualize and track their progress over time.

# User Stories

1. As a user, I want to be able to view the date I started a project/ hobby/activity
2. As a user, I want to be able to see the days since I started a project/ hobby/ activity
3. As a user, I want to be able to add an activity manually, adding tha name, date, location 
4. As a user, I want to be able to see the number of times I have done activity
